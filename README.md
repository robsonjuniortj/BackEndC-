# 🌍 BackEndC- | API Backend em C#

Backend desenvolvido em C# durante a formação Full Stack da Recode Pro para integração com o projeto frontend em React do sistema de viagens.

O projeto foi criado utilizando arquitetura separada entre frontend e backend, simulando uma aplicação web moderna com comunicação via API REST.

---

## 🚀 Tecnologias Utilizadas

- C#
- .NET
- ASP.NET
- API REST
- JSON
- Git & GitHub

---

## 🎯 Objetivo do Projeto

Desenvolver a parte backend de uma aplicação de viagens, responsável por:

- Gerenciamento de dados
- Integração com frontend React
- Organização das rotas da aplicação
- Estruturação da API
- Simulação de ambiente full stack profissional

---

## ⚙️ Funcionalidades

✅ Estrutura backend separada  
✅ Endpoints API REST  
✅ Comunicação com frontend React  
✅ Organização em arquitetura web  
✅ Manipulação de dados da aplicação
